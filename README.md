В данном репозитории собраны задания, выполненные в ходе производственной практики в компании MediaSoft по направлению «Системная аналитика».

Список работ:

Задание 1: Формирование бизнес- и функциональных требований (ТЗ).

Задание 2: Построение BPMN-диаграммы процесса бронирования.

Задание 3: Проектирование ER-диаграммы (модели базы данных).

Задание 5: Написание SQL-запросов в PostgreSQL (JOIN, GROUP BY, подзапросы).

Задание 7: Проектирование REST API (эндпоинты, контракты запросов и ответов).

Задание 8: Описание Use Cases и сопоставление их с конечными точками API.
